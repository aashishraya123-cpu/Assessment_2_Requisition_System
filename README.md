# Assessment 2 - Requisition System

## Project Overview
This is my Python Requisition System for Programming Assessment 2. The program helps staff create purchase requests and allows managers to make approval decisions.

## Features
- Create requisitions with staff details
- Generate unique requisition IDs
- Calculate the total cost of requested items
- Automatically approve requests below $500
- Allow managers to review pending requests
- Display requisition details and approval references
- Show requisition statistics

## Tools Used
- Python
- Visual Studio Code
- Git and GitHub

## Testing
I tested the program using different requisition amounts, approval decisions, and Python assertions to check that the system works correctly.

## How to Run
1. Download the project.
2. Open requisition_system.py in Visual Studio Code.
3. Run the Python file.
